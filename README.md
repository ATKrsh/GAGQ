# GAGQ - Antigravity Quota & Credit Monitor

GAGQ is an Antigravity extension and dashboard that displays remaining weekly and daily quota as well as AI credits for all available AI models in real-time for the logged-in account.

## Features
- **Real-Time Quota Tracking**: Monitor daily and weekly remaining quotas per model.
- **AI Credit Balance**: Track account-wide AI credits and usage history.
- **Account Status**: Dynamic detection of the active logged-in user session.
